# Library Demo Run Guide

## Prerequisites

- Python 3 installed
- Git installed
- Repository cloned to your computer

## exact command of python3 run.py demo

Library loan demo (fixed date: 2026-09-01)
Student limit: 2
Faculty limit: 2
Search for 'git': []
Loan: Git Essentials
Borrowed by: Alex; due: 2026-09-15
Return fee: 0
Active loans after return: 0

## short description

The demo shows the library loan system in action. It displays loan limits, performs a book search, borrows a book, shows its due date, returns the book, and displays the return fee and active loans.
